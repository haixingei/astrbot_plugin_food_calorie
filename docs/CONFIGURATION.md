# 配置说明

配置文件由 AstrBot 管理端生成，通常在：

```text
AstrBot/data/config/astrbot_plugin_food_calorie_config.json
```

也可以在 **管理端 → 插件 → 食物卡路里提醒** 里修改。改完重启 AstrBot 生效。

## 最小可用配置

```json
{
  "enable": true,
  "trigger_mode": "auto",
  "group_ids": ["123456789"]
}
```

只配置 `group_ids` 就可以在群里使用。默认不会在任何群或私聊生效，避免安装后误触发。

## 字段详解

### `enable`

- 类型：`bool`
- 默认：`true`

总开关。关掉后，插件不会检查图片，也不会改 system prompt。

### `trigger_mode`

- 类型：`string`
- 可选：`auto` / `keyword`
- 默认：`auto`

| 模式 | 行为 |
| --- | --- |
| `auto` | 目标会话里发图片就追加提示；模型自己判断是不是食物、要不要聊热量 |
| `keyword` | 只有图片同时带关键词，或文字以 `/热量`、`/卡路里`、`/kcal` 等开头时才追加提示 |

如果你只想在用户**明确问热量**时提示，选 `keyword`；如果你希望 AI 看到食物图就自然聊一句，选 `auto`。

### `trigger_keywords`

- 类型：`list[str]`
- 默认：`["卡路里", "热量", "多少卡", "大卡", "kcal", "会胖", "减肥", "吃了多少"]`

命中后，提示会额外要求回复带一个大概数字。关键词不区分大小写。

### `group_ids`

- 类型：`list[str]`
- 默认：`[]`

允许生效的 QQ 群号。支持字符串或数字，内部会统一成字符串。

**为空时群聊完全不生效。**

获取群号的方法：

- 在 AstrBot 日志里查看消息来源的群号；
- 或在 OneBot / SnowLuma 的群信息里查看。

### `enable_private`

- 类型：`bool`
- 默认：`false`

是否启用私聊。默认关闭。

### `private_ids`

- 类型：`list[str]`
- 默认：`[]`

私聊白名单 QQ 号。

安全行为：即使 `enable_private=true`，只要 `private_ids` 为空，也**不会匹配任何私聊**。这避免安装后全量生效。

### `hint`

- 类型：`text`
- 默认：空（使用内置提示）

自定义追加给模型的提示。它只会拼接在本次请求的 system prompt 末尾，不写入聊天历史。

写自定义提示时，建议保留：

- 用日常口气；
- 不要列清单/报告体；
- 看不清或不是食物时别硬猜；
- 明确问热量时给大概数字。

示例：

```text
图片里如果是吃的，就用轻松自然的口气说说它大概多少大卡，像朋友聊天一样；
不要用“识别到/估算/根据图片”这些词；看不清就别猜。
```

### `log_injections`

- 类型：`bool`
- 默认：`true`

是否在日志记录“本次请求已注入提示”。不会记录聊天正文。

## 触发条件（必须同时满足）

1. `enable=true`；
2. 当前消息含图片；
3. 当前会话在白名单里（群号或私聊 QQ）；
4. `trigger_mode=auto`，或 `keyword` 模式下命中了关键词/指令；
5. 同一条消息没有已经注入过（插件内部去重）；
6. AstrBot 当前模型能处理图片（这是模型能力，不是插件能补的）。

## 与会话合并插件共存

本插件只挂 `on_llm_request`，不直接回复、不中止事件。

如果使用会话合并插件：

- 文字 + 图片可以先合并成一次请求；
- 本插件只给这次请求补一次提示；
- 最终只由模型回一条，不会出现“插件卡片 + 普通回复”。

## 修改配置后

重启 AstrBot，或使用 AstrBot 的插件重载功能。只修改 JSON 文件但没有重载时，运行中的插件仍使用旧配置。

## 排查

| 现象 | 检查 |
| --- | --- |
| 完全没反应 | `enable` 是否为 true；`group_ids` 是否填了当前群 |
| 群聊有效、私聊无效 | `enable_private=true` 且 QQ 在 `private_ids` |
| 发图没触发 | 当前消息里是否真的包含 `Image` 组件；是否是纯文本/链接 |
| `keyword` 模式不触发 | 关键词是否命中；或者改用 `auto` |
| 模型说看不到图 | 当前模型不支持图片输入，换支持 vision 的模型 |
| 回复太刻意 | 自定义 `hint`，要求更口语、不要报告体 |
| 出现两条回复 | 检查是否有旧版食物插件/其他插件也在直接回复；本插件本身不发消息 |
