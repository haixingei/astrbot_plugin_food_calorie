# 隐私与安全说明

## 插件做什么

插件只做一件事：在 `on_llm_request` 阶段检查当前消息是否含图片、是否在白名单会话里，如果命中，就在**本次请求的 system prompt 末尾追加一小段文字提示**。

它不：

- 不下载、保存或上传图片；
- 不直接调用视觉 API；
- 不直接发送聊天消息；
- 不写入聊天历史、数据库或长期记忆；
- 不读取文件系统；
- 不访问网络；
- 不注册管理员命令。

## 数据流

```text
用户图片
  │
  ├─ 由 AstrBot 当前配置的模型处理（遵循你使用的模型供应商策略）
  │
  └─ 插件只检查消息里有没有 Image 组件、是否在目标会话
        │
        └─ 命中时，在本次请求 system prompt 末尾追加提示
```

图片的识别、传输和留存取决于 AstrBot 的模型配置与模型供应商，不由本插件控制。

## 插件会留下什么

- **不保存业务数据**；
- AstrBot 日志可能记录一条注入状态，例如：

  ```text
  [食物热量] 已把「自然聊热量」提示并入本次请求（群，明确问热量）
  ```

  这条日志不包含聊天正文、图片或热量数字。

- 插件配置本身由 AstrBot 管理端保存；其中可能包含群号和 QQ 白名单。请不要把真实配置提交到公开仓库。

## 安全默认值

- `group_ids` 默认空 → 安装后群聊不生效；
- `enable_private` 默认 `false` → 私聊默认关闭；
- `private_ids` 默认空 → 即使误开私聊，也不会匹配任何私聊；
- 只有显式配置的群/QQ 才会注入。

## 建议

- 不要在公开 issue/截图里暴露真实群号、QQ 号或自定义提示中的隐私信息；
- 公开仓库只提交示例配置，不提交 `data/config/` 下的真实配置；
- 如果使用第三方模型，请阅读其数据使用政策；
- 本插件不提供营养学或医疗建议，热量只是图片可见内容的粗略估计。

## 漏洞报告

如果发现安全问题，请优先通过仓库的私密安全报告渠道联系作者，不要在公开 issue 里贴出真实配置或聊天截图。
